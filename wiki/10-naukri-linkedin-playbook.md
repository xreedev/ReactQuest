# 10 — Naukri / LinkedIn Playbook & Designation Ladders

Your CV gets you through the human scan. **Your profile is what generates the call.** Most candidates polish the PDF and neglect this, then conclude they have a skill problem.

## Naukri mechanics

**Resdex is bidirectional.** Recruiters find you through database searches even if you never applied to their posting. That makes passive visibility the main lever.

**How recruiters actually search:** Boolean-style filtering (AND / OR / NOT) over 100M+ profiles, but through separate Any/All/Exclude keyword boxes capped around 500 characters. Practical consequence: **few, short, exact keywords.** Long elegant phrasing loses.

**How you rank:** profile completeness · keyword match · profile views · recency. Profiles with the searched term in the headline rank higher and appear in the featured section.

### Field-by-field

| Field | What to put |
|---|---|
| **Headline** (~60 chars) | `React Developer \| 3.5 Yrs \| JavaScript, TypeScript, Redux \| [City]` — not "Passionate developer who loves clean code" |
| **IT Skills** | Every technology with version and experience level. This is a primary search target. |
| **Current CTC / Expected CTC** | Fill them. Common recruiter filters. |
| **Notice period** | Fill it. Blank = removed from filtered searches. |
| **Preferred locations** | Fill both spellings where relevant (Bangalore / Bengaluru) |
| **Status** | "Actively looking" — "Passive" makes you near-invisible |
| **Resume upload** | The ATS-formatted single-column version from `08` |
| **Freshness** | Small edits (headline tweak, add a skill) signal an active profile |

### Synonym coverage
Title vocabulary varies widely — backend developer / software engineer / SDE / full-stack engineer often mean the same thing to different recruiters. Include the variants that are true for you: "React.js / ReactJS", "Frontend Developer / UI Developer".

### What not to bother with
- **Auto-apply** converts poorly; uncustomised bulk applications rarely generate interviews. Manual targeted applications consistently outperform.
- Paid résumé-writing services: quality varies; skip if you already have a good CV.
- Profile Booster: arguably worth 1–2 months *only* when the profile is already fully optimised.

## LinkedIn

Channel split reported by recruiters: **Resdex for junior-to-mid volume requisitions; LinkedIn for senior and passive searches.** Most senior tech shortlists in India still pass through LinkedIn before an offer.

At 3+ years you need both, weighted to Naukri. Keep the LinkedIn headline identical to the Naukri headline for consistency, and keep the "Open to work" recruiter-only setting on.

## Referrals

Community reports consistently rate referral as the more reliable route to a first call than portal application at these companies — one Infosys thread states it plainly. If you have any ex-colleague inside a target firm, that path beats CV optimisation.

## Enterprise ATS (direct applications)

Large Indian IT firms run their own enterprise ATS for direct applications (Taleo, SAP SuccessFactors, iCIMS have been named; startups and product companies use Greenhouse, Lever, Workday). Different parsers, same rule: **plain structure survives, decorated structure doesn't.**

⚠️ Specific product attributions (e.g. "Infosys uses iRecruit + SmartRecruiters", "Wipro uses Phenom People") come from resume-tool vendors with a commercial interest and no primary sourcing. Treat the named products as unverified; treat "parsed and scored before a human sees it" as solid.

## Designation ladders — speak the market's language

Crowd-sourced and inconsistent between sources; treat as approximate.

| Company | Ladder (approx.) | Where a 3+ yr React dev sits |
|---|---|---|
| **Accenture** | L13 entry → L12 Associate Software Engineer → L11 Software Engineer → L10 Senior Software Engineer → L9 Team Lead/Specialist (other accounts map slightly differently; nomenclature has changed) | **L10 / L9** — "Application Development Analyst / Senior Analyst" |
| **TCS** | Assistant System Engineer Trainee → Assistant System Engineer → Systems Engineer → … | **Systems Engineer / IT Analyst** |
| **Infosys** | JL-graded; System Engineer at JLB3 entry band | **Senior Systems Engineer → Technology Analyst** |
| **Wipro** | Developer L1 / L2 / L3 | **Developer L3** (3–5 yrs) |

**Practical use:** if your current title is non-standard ("Software Engineer II", "Member Technical Staff", "UI Developer"), keep the official title **and** add the market-standard function beside it — `Software Engineer (Frontend / React)` — so both the recruiter's mental model and the keyword search match.

## The uncomfortable one

Blind/Fishbowl respondents report that some firms reject profiles outright when current CTC is high relative to years of experience. **No résumé formatting fixes a CTC-band mismatch.** If you're consistently unshortlisted despite a clean profile, check your CTC positioning against the band before rewriting bullets again.
